# AI 编程与 Agent 工作流

## Purpose

维护 cofol1986 使用 Codex、Claude Code、Hermes、Kanban、多 Agent、TDD、代码审查和工程计划的长期方法体系。

## Maintenance standard

- 新项目先做项目启动包 / PRD / 架构 / Plan，不直接编码。
- 工程任务优先 Heavy Kanban 和多 Agent 并行。
- 实现任务尽量双 Review。
- 复杂任务需要验证器：测试、benchmark、E2E、验收 checklist。
- 从实践中沉淀 skills 和 playbooks，而不是只留聊天记录。
