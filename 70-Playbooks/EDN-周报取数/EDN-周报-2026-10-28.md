<h3>1. 执行结论</h3>

<p><b>结论一：EDN 的 SaSo 商业化前置条件不是产品功能完成度，而是「可验收结果对象」的设计——本周有三家厂商给出了三种范式，EDN 还没选。</b> Cisco 的范式是「把网络意图编译成可执行路径 + 用测量证明承诺已兑现」（SRv6/Flex Algo/BGP + 响应时间/辖区/成本档位可核销）；Extreme 的范式是「把闲置基础设施变成新的可售结果」（Exchange zones，把网络算力转成 AI 基础设施产品）；ServiceNow 的范式是「把运维成本本身做成可计量下降」（补丁 2000-3000h → <60h，团队人数不变）。三者共同点：结果定义在<b>服务契约层</b>而不是功能层。EDN 若先选「按会议质差率收费」再去找测量方法，会重蹈「先有收费形式、后补度量」的路径。（H1）</p>

<p><b>结论二：Agentic Ops 的竞争已经进入「数字对数字」阶段，EDN 处于裸奔状态，且差距是量级差不是口径差。</b> 竞品当前可出示的基线：事件量 −90%、补丁工时降 97%+、自修复率 70-80%、根因定位 20 分钟 → 3 分钟、Root cause 成功率 75%、关键提示执行率 98%、首月省 1,000 小时。EDN 目前能出示的只有功能清单。没有基线数字时，PLG 场景里「AI 运维」的对话会被直接压缩成「你的 AIOps 覆盖率是多少」。<b>这是本周最高优先级的单点缺口，不是能力 gap 而是度量 gap。</b>（H1）</p>

<p><b>结论三：中文市场的叙事权争夺已经开始，EDN 的时间窗比上个季度更短。</b> H3C 已用「联合中国信通院发布建设指南」的方式把智能广域网的定义权握在手里，且定义内容（感知-分析-决策-执行闭环、分钟级自愈、意图接口、数字孪生变更仿真）与 EDN 的 S5 + Agentic Ops 路线高度重叠；华为 AgenticCore 用 QoAIS 把 S4 的体验保障目标函数从「人开会不卡」换成「AI 服务达成质量」，并预告 2030 年人均 10 个智能体（H1）。两家一个有标准背书、一个有架构定义权，EDN 在中文市场目前既无标准参与也无指标定义权。<b>建议把「EDN 指标体系白皮书」从远期动作提前到本季度。</b>（H1/H3）</p>

<h3>4. 领域演化</h3>

<p><b>Agentic Ops</b> — 从「给运维人看」彻底转向「给 agent 供给上下文并让它执行」。三条同构的技术栈已经成型：(a) Cisco = MCP 作为 agent 连接监控/修复的通用语言 + Crosswork AI 集成开放模型可本地部署；(b) Extreme = Agent ONE Coworker（理解意图、模拟用户行为、主动行动）+ Operator（自主调查-规划-行动，受治理边界约束）；(c) WWT = agentic 层之上必须保留确定性自动化层。买方侧的反向约束同样清晰：Danfoss CIO 指出职责分离（segregation of duties）意味着不能给 agent 全域访问，Sune Tornbo Baastrup 直言 agent 编排平台目前多为「agent 清点目录」而非真正编排。（H1/H2）</p>

<p><b>SaSo / 结果定价</b> — 本周的三个范式已在上文给出（Cisco 的 assured outcome / Extreme 的结果型新服务 / ServiceNow 的成本下降）。需求侧的清醒证据也同步出现：Cato Networks 的模块化定价（AI Security、SD-WAN、SSE、Universal ZTNA 四个独立模块，前 12 个月可逐步部署许可、按用户数与站点带宽计价、99.999% uptime SLA）说明买方仍要求「按现有用量起步」，Dell'Oro 指出 SSE 中独立变现的 Data Security 与 DEM 增长快于基础接入检测。Cloudflare 的 Pay Per Use 与 Monetization Gateway 则把 agent 时代的计量/结算直接摆上台面。（H1）</p>

<p><b>可观测性 / Telemetry</b> — 竞争维度从「采全」转为「上下文可被 agent 消费」。XCOR Fabric 的四层（Knowledge Graph / Operational Memory / User Behavior / Human Knowledge）本质上是在回答「agent 缺什么上下文」；NVIDIA Minerva 把指标收敛到 AI factory yield（GPU hours/goodput/uptime/token 产出）；Splunk 侧 SVP Kamal Hathi 的口径一致——可观测性通过引入护栏并把 AI 用量与 token 成本关联到可测量业务结果，让 AI 支出更可预测。背景数据：42% 开发者称 AI 已写至少一半代码（去年 12%），遥测增速已超过运维人力增速。（H1）</p>

<p><b>Zero Trust / SASE-SSE</b> — 三个趋势叠加：(a) 平台归并但不合并控制面（HPE 把 EdgeConnect 塞进 Mist/Central，同时坚持两个平台保留）；(b) 接入层被云化替代（Fortinet FortiLink 让整个 LAN 无防火墙接入 SASE，Nile 走 Secure NaaS 让客户免运维）；(c) agent 成为新的 Zero Trust 主体（Zscaler 的「访问失败而非推理失败」、PANW Idira 的机器身份 109:1、SPIFFE/SVID、ZSP）。Palo Alto 的 Prisma SASE 被定位为「第一个 Agentic SASE」。（H1）</p>

<p><b>Campus Fabric / WLAN</b> — Wi-Fi 8 与 edge/agentic AI 同时登场（Qualcomm + Dragonwing SAM）；HPE 新 Central 明确把第三方老旧交换机纳入 AI 引擎与可见性，并给出会员数口径（20+ 万客户、22+ 集群）；华为 F5G-A 全光园区把 50G PON、Wi-Fi 感知、Wi-Fi 7 物联光 AP、运维智能体打包成一体方案，全球已有 18,000+ 园区采用全光方案。（H1）</p>

<p><b>Ethernet / Silicon / 白盒</b> — 三条硬约束同时逼近：SONiC 企业化（650 Group 预测 2026 年 SONiC 数据中心交换收入超 50 亿美元、企业采用到 2027 年同比超 25%；Dell'Oro 预测 AI scale-out 的 SONiC 销售到 2030 年年增超 50%、收入超 100 亿美元；Gartner 估 2,500 家组织生产运行 SONiC、约三分之一为企业）；USFP 封装密度竞争；物理封装极限（Arista + Jabil：机柜功耗 30-40 kW 已实测、目标 60→120 kW，单柜 2,000-4,000 根光纤，16 交换机机柜布线 3-4 天人工，备件策略已失效）。（H1）</p>

<p><b>Digital Twin</b> — 从数据中心概念下沉为变更流程的前置闸门。H3C 变更智能体在数字孪生环境完成仿真校验与风险校验后才下发全网设备，配一键回滚与全过程审计；Huawei MindOps 把网络数字孪生与 NetLIVE 仿真平台、BestDC、SmartCare 组合成 AI-native 工具链并作为 IDC MarketScape Leader 的论据。NVIDIA + Schneider Electric 同期测试数据中心运营数字孪生。（H1）</p>

<p><b>Silicon 生态 / 芯片</b> — 内存短缺正在成为网络市场的价格主线（DDR4 缺货推高设备 ASP，2Q26 园区交换机端口出货 −5% 而 ASP +19%）。这与 EDN 的软件订阅叙事构成反作用力：客户在硬件涨价周期里更倾向把预算集中在换新设备，而不是买软件。（H1）</p>

<p><b>新兴架构 / 量子安全</b> — Toshiba 的 QSN 平台把「harvest now, decrypt later」推到平台级；PANW 把 quantum-safe security 列为 Hybrid Mesh Firewall 的四大能力之一。（H1）</p>

<p><b>Agentic AI 安全</b> — Unit 42 本周披露的攻击者实证最值得 EDN 关注：BUGSTER 用 Hermes Agent 框架 + DeepSeek V4 作推理引擎、Cursor IDE 作辅助（安全控制全关），对印度两所高校发起 AI 生成暴力破解，确认入侵第二所并外泄 5,200+ 条含学生 PII 的数据库，同时具备需要物理接近的 Wi-Fi 密码破解能力。<b>结论：网络接入层已经是 agent 化攻击的实际落地面，不只是防御对象。</b>（H1）</p>

<h3>6. 跨厂商模式识别</h3>
<p><b>收敛</b>：所有一线厂商都在讲同一套四层结构——① 确定性执行层（保留人工审批或确定性自动化）② agent 层（自主调查-规划-行动）③ 上下文层（知识图谱/数字孪生/运营记忆）④ 治理层（身份、最小权限、护栏、可解释）。H3C 的建设指南、Cisco 的 Crosswork、XCOR 的 Fabric、H3C 数字孪生变更闸门，都是同一模板的中文化或产品化。（H1/H2）</p>
<p><b>分叉</b>：HPE 选择「能力对齐不合并平台」；Extreme 选择「把网络闲置算力商品化」；Cisco 选择「把现有路由机制编译成 intent」；Nile 选择「客户完全不碰设备」；华为选择「新平面 + 意图接口 + 身份认证」的架构级重写。同一诉求（自治 + 结果）下有五种产品哲学。（H1）</p>
<p><b>空白</b>：<b>没有任何一家把「异构环境下的自治」当作一等公民产品位</b>。HPE 有两个仍割裂的控制面；Nile 只覆盖自家 SecurePod；Cisco 的 Crosswork 绑定自家栈与 Nemotron；Extreme 的 Exchange zones 依赖自家 AP/交换机；华为的 NetMaster 在中文市场语境下也是自有栈。EDN 的「多厂商异构统一管控 + 可核验业务结果」仍是无人占据的位置——但这个位置正在从「特性」被重新定义为「可举证的产品合同」。（H3）</p>
<p><b>弱信号</b>：本周出现两个值得盯但尚不构成趋势的信号——(a) Dell'Oro 提出「AI 时代网络价值重塑」的 UBBF 观察（三 R 框架），说明卖方研究机构开始为网络价值重构建叙事，但仍是观点非数据；(b) Toshiba 的 QSN 把量子安全做成网络平台而非安全附加品，目前仅一家成体系推出。（H2）</p>
<p><b>非显而易见</b>：<b>Unit 42 抓到的攻击者用的是 Hermes Agent 框架</b>——这意味着 agent 化攻击的门槛已经降到「装个开源 agent 框架 + 关掉安全控制」，而攻击目标是 Wi-Fi 密码与 VoIP 欺诈这类网络接入层。EDN 的 S6 终端统一管理若只做「管终端软件版本」，会漏掉这一整类攻击面（凭据被 agent 化提取与滥用）。这是本周唯一一条既指向攻击方也指向 EDN 产品定义的证据。（H1/H3）</p>

<h3>7. EDN 启示</h3>
<p><b>架构影响</b>：S1 统一数据底座必须按「agent 上下文供给层」重新定义 schema，而不是按「被管设备台账」定义——参照 XCOR Fabric 四层，至少要能产出：跨域拓扑与依赖关系、历史故障的运营记忆、资深工程师实际使用的查询模式、runbook 与知识条目。同时 S1 需要承接 agent 身份与最小权限（S2 同源），否则 agent 无法安全地在异构设备上动作。（H1/H3）</p>
<p><b>产品能力 gap</b>：三处：(a) <b>缺 S4「会议质差率」与 agent 任务耗时的可归因度量</b>——竞品已有 −90%、75% 成功率、98% 执行率、<60h 补丁等量级基准，EDN 无任何同类数字；(b) <b>缺 agent 权限治理与证据链</b>——Zscaler 的 AI Access Graph、PANW 的 SPIFFE/SVID + ZSP、HPE 的 MCP 发现与凭据管理，指向同一需求；(c) <b>缺「确定性执行层」这一显式架构层</b>——WWT 明确要求 agentic 层之下保留确定性自动化层，EDN 当前架构图里没有这一层的显式位置。（H1）</p>
<p><b>GTM / 服务影响</b>：必须并行准备 MSP 打包路径——Cato 的模块化渐进许可、Nile 的免运维 NaaS、H3C 的 Partner First 都在降低客户首次承诺门槛；EDN 6 月海外切纯订阅会正面撞上 Dell'Oro 描述的「硬件涨价 + 客户提前采购」窗口，PLG 论证必须能回答「为什么现在买软件而不是换 Wi-Fi 7 设备」。（H1/H3）</p>
<p><b>差异化机会</b>：EDN 唯一未被占位的位置是「异构环境下唯一能出具可核验业务结果的平台」。本周三家给出的范式（Cisco 的路径可核销、Extreme 的资产可售、ServiceNow 的成本可下降）说明市场已接受「结果型产品」这个形态，只是不接受没有度量能力的结果型叙事。EDN 应把「统一管控」重新包装为「统一度量 + 统一执行 + 统一举证」的合同能力。（H3）</p>
<p><b>竞争风险</b>：H3C 联合信通院出标准 + 华为定义架构 + QoAIS 换目标函数 + HPE 有 70-80% 自修复数字 + 极端案例（Unit 42 的 Wi-Fi 密码 agent 攻击）——三面夹击下，EDN 的窗口在收窄。中文市场尤其紧迫：竞品已经在定标准、定义「智能体网络」，而 EDN 的对标内容（星河 AI / NetMaster）还停留在厂商宣传语层面，缺少第三方可核验数字。（H1/H3）</p>

<h3>8. 推荐行动</h3>
<p><b>近期（30 天内）</b>：(1) <b>产出 S4 质差率测量规范与归因方法论</b>，跑出至少两个可对标竞品的内部基线数字（建议对齐 ServiceNow 的「事件量下降 %」与 XCOR 的「根因定位时长 + 成功率」两个口径）；(2) <b>起草《EDN 网络自治指标白皮书》</b>，对标 H3C《ICT 智能体建设指南》的结构，抢占指标定义权；(3) S1 架构评审加入「agent 上下文供给层」与「确定性执行层」两个显式层次，输出 schema 变更清单。（H1/H3）</p>
<p><b>中期（1-2 季度）</b>：(1) S2 增加 agent 身份、最小权限与动作证据链（对标 Zscaler AI Access Graph 与 PANW SPIFFE/SVID + ZSP）；(2) S4 指标体系新增 agent 任务耗时/token 消耗维度（承接华为 QoAIS 的目标函数变更）；(3) S1 第三方设备可见性先行——把「能纳管异构」升级为「异构设备的统一可举证遥测」，先于对端平台收敛动作（HPE 已把第三方老旧交换机纳入 AI 引擎，这是可对标动作）；(4) S6 纳入 agent 化凭据窃取路径的检测（依据 Unit 42 BUGSTER 案例：Wi-Fi 密码破解 + VoIP 欺诈 + 物理接近）。（H1/H3）</p>
<p><b>长期</b>：SaSo 商业化设独立 gate，通过条件为「存在一个客户可验收、EDN 可举证、可持续计量的结果对象」，而非产品功能完成度或订阅切换时点；建议候选优先从 S4 体验结果切入，避开 SD-WAN 带宽类结果（已被 Cisco 以 SRv6/Flex Algo/BGP 路线占位且更底层）。（H1/H3）</p>
