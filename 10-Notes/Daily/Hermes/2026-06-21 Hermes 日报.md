- **撤 cron 是"修完根因"而不是"补 cycle.sh"**：今天在修飞书循环时，Hermes 一度被"用什么 CLI 替代 cycle.sh"卡住，差点写出同款草稿（plan B/plan A 都还在重启循环里打转）；最终选 C = 找到根因（cron 本身是 6/20 升级的临时草稿）一次性撤掉。这条经验已记入 memory：**遇到"我每分钟都要做 X 才正常"时，第一反应应该是"X 是谁布置的、能不能撤掉"，不是"怎么让 X 更稳"。**
- **`hermes plugins list` 显示 enabled 不代表运行时 REGISTERED**：今天发现 plugin 在 metadata 启用但运行时根本没 import；判断 plugin 是否真生效要看 `gateway.log`/`errors.log` 里的 `REGISTERED` 行 + 实际 hook 是否触发（用户 hello 没改名 = 没触发），不能只看 CLI 列表。已记入 memory。
- **SIGUSR1 不是"安静 reload"**：测试已证伪；以后再遇到"想热加载 X 但不想刷通知"的场景，正确做法是 `hermes gateway restart --system`，而不是 SIGUSR1。
